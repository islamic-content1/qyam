# ختمة القيام

جدول متابعة ختمة القيام بشكل Excel لخمس فتيات، يعمل على GitHub Pages ويحفظ البيانات في Firebase.

## محتوى المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `style.css` | التنسيق (شكل Excel) |
| `script.js` | منطق الجدول وتسجيل الدخول والحفظ |
| `firebase-config.js` | إعدادات Firebase وأسماء الفتيات |
| `firestore.rules` | قواعد حماية قاعدة البيانات |
| `manifest.json` | اسم وأيقونة الموقع عند إضافته للشاشة الرئيسية |
| `icons/` | صورة التطبيق (الأيقونة) |
| `fonts/` | مكان ملف خط طفولي |

---

## 1) خط Tufuli Arabic

خط **Tufuli Arabic غير موجود على Google Fonts**، لذلك يُحمَّل من ملف داخل المشروع:

1. حمّلي الخط (نسخة DEMO مجانية للاستخدام الشخصي) من مثلًا:
   https://www.1001fonts.com/tufuli-arabic-demo-font.html
2. فكّي الضغط وخذي ملف الخط (`.otf` أو `.ttf`).
3. غيّري اسمه إلى أحد الأسماء التالية وضعيه داخل مجلد `fonts/`:
   - `TufuliArabic.otf`
   - أو `TufuliArabic.ttf`
   - (أو `TufuliArabic.woff2` إذا حوّلتيه)

إذا لم يُرفع الملف، يظهر الموقع بخط احتياطي مستدير قريب منه (Baloo Bhaijaan 2).

---

## 2) إنشاء مشروع Firebase

1. ادخلي إلى https://console.firebase.google.com واضغطي **Add project**.
2. اكتبي اسم المشروع (مثل `khatma-qiyam`) وأكملي الخطوات (يمكن إيقاف Google Analytics).

### أ) إضافة تطبيق ويب وأخذ الإعدادات

1. من صفحة المشروع اضغطي أيقونة **Web `</>`**.
2. اكتبي اسمًا للتطبيق واضغطي **Register app** (لا تفعّلي Hosting).
3. سيظهر كود فيه `firebaseConfig`. انسخي القيم وضعيها في ملف **`firebase-config.js`** مكان:
   ```js
   apiKey: "PASTE_API_KEY_HERE",
   authDomain: "PASTE_PROJECT_ID.firebaseapp.com",
   projectId: "PASTE_PROJECT_ID",
   storageBucket: "PASTE_PROJECT_ID.appspot.com",
   messagingSenderId: "PASTE_SENDER_ID",
   appId: "PASTE_APP_ID"
   ```
   هذه القيم ليست سرية، ولا بأس أن تكون في GitHub. الحماية تتم عبر القواعد (الخطوة د).

### ب) تفعيل تسجيل الدخول

1. من القائمة: **Build → Authentication → Get started**.
2. تبويب **Sign-in method** → اختاري **Email/Password** → فعّلي أول خيار → **Save**.
3. تبويب **Settings → User actions** → **ألغي تفعيل** خيار **Enable create (sign-up)** ثم **Save**.
   (حتى لا يستطيع أحد إنشاء حساب جديد من خارج الموقع.)

### ج) إنشاء حسابات الفتيات الخمس

من **Authentication → Users → Add user** أضيفي خمسة مستخدمين بهذه الإيميلات **بالضبط** (الإيميل ليس حقيقيًا ولا يحتاج تفعيل):

| الفتاة | Email | Password |
|---|---|---|
| منار | `manar@qiyam-khatma.app` | كلمة مرور تختارها منار |
| لور | `lour@qiyam-khatma.app` | كلمة مرور تختارها لور |
| لمى | `lama@qiyam-khatma.app` | كلمة مرور تختارها لمى |
| هيا | `haya@qiyam-khatma.app` | كلمة مرور تختارها هيا |
| زينة | `zeina@qiyam-khatma.app` | كلمة مرور تختارها زينة |

- كلمة المرور 6 أحرف على الأقل.
- أرسلي لكل فتاة كلمة المرور الخاصة بها فقط.
- عند الدخول للموقع تختار الفتاة اسمها وتكتب كلمة المرور، ولا تحتاج كتابة الإيميل.
- كلمات المرور محفوظة في Firebase فقط، وليست موجودة في أي ملف من ملفات الموقع.

### د) إنشاء قاعدة البيانات Firestore والقواعد

1. **Build → Firestore Database → Create database**.
2. اختاري موقعًا قريبًا (مثل `eur3` أو `europe-west`) → **Start in production mode** → **Create**.
3. افتحي تبويب **Rules**، احذفي كل ما فيه، والصقي محتوى ملف **`firestore.rules`** كاملًا، ثم **Publish**.

القواعد تضمن من قاعدة البيانات نفسها:
- القراءة مسموحة فقط للفتيات الخمس بعد تسجيل الدخول.
- كل فتاة تكتب في الشيت الخاص بها فقط (`sheets/manar` لمنار فقط، وهكذا).
- لا يمكن حذف أي شيت، ولا يُقبل إلا الحقلان `done` و `notes`.

> لا تحتاجين إنشاء أي Collection يدويًا؛ الشيت يُنشأ تلقائيًا أول مرة تضغط فيها الفتاة «تم» أو تكتب ملاحظة.

### هـ) السماح لرابط GitHub Pages بتسجيل الدخول

بعد رفع الموقع (الخطوة 3):
**Authentication → Settings → Authorized domains → Add domain** وأضيفي:
```
USERNAME.github.io
```
(استبدلي `USERNAME` باسم حسابك على GitHub.)

---

## 3) رفع المشروع إلى GitHub Pages

1. ادخلي إلى https://github.com/new وأنشئي Repository جديدًا (مثل `khatma-qiyam`)، واجعليه **Public**.
2. في صفحة الـRepository اضغطي **Add file → Upload files**.
3. اسحبي **كل محتويات** مجلد المشروع (الملفات + مجلدي `icons` و `fonts`) وليس المجلد نفسه، بحيث يكون `index.html` في الجذر.
4. اضغطي **Commit changes**.
5. من **Settings → Pages**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` و المجلد `/ (root)` → **Save**.
6. بعد دقيقة أو دقيقتين يظهر الرابط:
   ```
   https://USERNAME.github.io/khatma-qiyam/
   ```
7. لا تنسي إضافة `USERNAME.github.io` في Authorized domains (الخطوة 2-هـ).

### لاحقًا عند تعديل أي ملف
ارفعي الملف الجديد بنفس الطريقة (**Add file → Upload files**) وسيُستبدل تلقائيًا.

---

## 4) إضافة الموقع للشاشة الرئيسية في الهاتف

- **iPhone (Safari)**: زر المشاركة → **Add to Home Screen**.
- **Android (Chrome)**: القائمة ⋮ → **Add to Home screen**.

تظهر صورة «شرف المؤمن قيام الليل» كأيقونة للتطبيق.

---

## 5) طريقة الاستخدام

- تختار الفتاة اسمها وتكتب كلمة المرور.
- يفتح الشيت الخاص بها مباشرة، وتبويبها مكتوب بجانبه «(أنا)».
- الضغط على مربع **تم** يضع علامة صح خضراء ويسجل تاريخ اليوم ويحفظه.
- إلغاء العلامة يحذف التاريخ.
- الملاحظة تُحفظ تلقائيًا بعد التوقف عن الكتابة.
- التبويبات في الأسفل تفتح شيتات الصديقات للمشاهدة فقط.
- التحديثات تظهر مباشرة عند الجميع دون إعادة تحميل الصفحة.
